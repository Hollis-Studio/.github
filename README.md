# Hollis Studio

Hollis Studio is building a connected health and wellness platform designed to help people make better day-to-day decisions about training, recovery, nutrition, movement, and mental wellbeing.

## How the Hollis suite is structured

Hollis is organized as one unified system with focused apps, not a collection of unrelated products:

- **Hollis Health** – trusted health context and oversight
- **Hollis Workouts** – strength and training
- **Hollis Nutrition** – food and fueling
- **Hollis Recovery** – sleep/readiness and recovery guidance
- **Hollis Move** – mobility and low-impact movement
- **Hollis Mind** – stress and mental fitness support

Across the suite, Hollis uses shared identity, shared data contracts, and a common intelligence layer so each app can contribute to a clearer picture of a user’s overall health journey.

## What this organization contains

This GitHub organization hosts the repositories that power the Hollis suite, including app codebases, shared contracts, and supporting platform services.
